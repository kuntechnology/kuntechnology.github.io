# Kuntechnology 项目导航

这是 `https://kuntechnology.github.io/` 的纯静态首页，为四个内容不同的公开 GitHub Pages 项目提供统一入口。页面使用原生 HTML、内联 CSS、SVG 与 Canvas，无外部脚本、字体或私有项目数据。

## 项目入口

| 项目 | 用途 | 地址 |
| --- | --- | --- |
| UI 设计风格集锦 | 44 种 UI 风格、tokens、示例与提示词 | https://kuntechnology.github.io/ui-style-gallery/ |
| 输液提醒小助手 | 输液计时与提醒页面 | https://kuntechnology.github.io/iv-infusion-helper/ |
| 安恒信息安全服务方案 | 金融行业安全服务展示 | https://kuntechnology.github.io/Das-security/ |
| SFTP 安全传输可视化指南 | 交互式 SFTP / SSH 加密学习页面 | https://kuntechnology.github.io/sftp-visualization-guide/ |

## 首页体验与发布

首页使用原生 HTML、CSS、SVG 与 Canvas 实现星图、项目筛选和搜索；不依赖构建流程、外部脚本、字体或图片。动画响应减少动态效果偏好，页面切至后台时暂停 Canvas 更新，并限制 Canvas DPR 与粒子数量。

GitHub Pages 从 `main` 分支根目录发布；提交 `index.html` 后首页地址为 `https://kuntechnology.github.io/`。本仓库仅管理根站项目导航，不复制或迁移其他项目内容。
