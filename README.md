# Kuntechnology 项目导航

这是 `https://kuntechnology.github.io/` 的纯静态首页，为五个现有公开 GitHub Pages 站点提供统一入口。页面使用原生 HTML、内联 CSS 与本地 SVG，无外部脚本、字体或私有项目数据。

## 项目入口

| 项目 | 用途 | 地址 |
| --- | --- | --- |
| UI 设计风格集锦 | 44 种 UI 风格、tokens、示例与提示词 | https://kuntechnology.github.io/ui-style-gallery/ |
| 输液提醒小助手 | 输液计时与提醒页面 | https://kuntechnology.github.io/iv-infusion-helper/ |
| 安恒信息安全服务方案 | 金融行业安全服务展示 | https://kuntechnology.github.io/Das-security/ |
| Kuntech 安全方案页 | 与安恒信息方案页当前内容相同的独立入口 | https://kuntechnology.github.io/Kuntech/ |
| SFTP 安全传输可视化指南 | 交互式 SFTP / SSH 加密学习页面 | https://kuntechnology.github.io/sftp-visualization-guide/ |

## 发布

GitHub Pages 从 `main` 分支根目录发布；提交 `index.html` 后首页地址为 `https://kuntechnology.github.io/`。本仓库仅管理项目导航页，不复制或迁移各项目内容。
